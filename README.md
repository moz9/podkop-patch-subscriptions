# Podkop PE: установка и обновление

Здесь лежит канал выпусков Podkop PE: установщик в один файл, сведения о текущем выпуске и скрипт установки одной командой.

## Что нужно

- Роутер с OpenWrt 24.10 или 25.12 и LuCI.
- Процессор `aarch64_cortex-a53` (Xiaomi AX3000T, Redmi AX6, Cudy WBR3000UAX и подобные).
- Около 30 МБ свободного места на флеше и 45 МБ свободной памяти.

Установщик сам проверит роутер и скажет, если что-то не подходит. Режим `--check` только проверяет и ничего не меняет.

## Установка

Чистый роутер, Подкопа ещё нет:

```sh
wget -qO- https://raw.githubusercontent.com/moz9/podkop-patch-subscriptions/pe-release/install.sh | sh
```

На роутере уже стоит Подкоп (обычный или PE), его нужно заменить с сохранением настроек:

```sh
wget -qO- https://raw.githubusercontent.com/moz9/podkop-patch-subscriptions/pe-release/install.sh | sh -s -- --replace
```

Только проверить, подходит ли роутер:

```sh
wget -qO- https://raw.githubusercontent.com/moz9/podkop-patch-subscriptions/pe-release/install.sh | sh -s -- --check
```

Скрипт читает `manifest.json`, скачивает установщик для версии OpenWrt на роутере, сверяет его размер и SHA-256 с манифестом и только после этого запускает.

После установки: LuCI → Службы → Podkop → «Источники». Добавьте подписку или узел, выберите секцию и нажмите «Применить».

## Обновление

В панели: Podkop → «Диагностика» → блок «Обновления» → «Проверить», затем «Обновить». Роутер скачает новый установщик, сверит контрольную сумму и заменит установку. Настройки, подписки, узлы и результаты проверок сохраняются. Прокси при этом недоступен примерно 40 секунд.

То же вручную:

```sh
wget -qO- https://raw.githubusercontent.com/moz9/podkop-patch-subscriptions/pe-release/install.sh | sh -s -- --replace
```

## Удаление

```sh
podkop-uninstall
```

Роутер возвращается к состоянию до Подкопа: DNS провайдера, без таблицы файрвола, правил маршрутизации, заданий cron, служб и пакетов Подкопа; системные файлы LuCI возвращаются к оригиналам.

- `podkop-uninstall --dry-run` — показать, что будет сделано, ничего не меняя.
- `podkop-uninstall --keep-settings` — удалить код, оставить настройки и данные для следующей установки.

## Что в выпуске

- `podkop-pe-<версия>-openwrt24.10.run`, `podkop-pe-<версия>-openwrt25.12.run` — установщики (всё внутри, включая движок).
- `podkop-uninstall.sh` — скрипт удаления отдельным файлом.
- `manifest.json` — версия выпуска, размеры и контрольные суммы установщиков.
